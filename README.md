# 转发规则面板（装在中转机上）

这是一个装在中转 VPS 本机上的转发规则面板，路子和 3xui 一样：装到机器上、服务常驻、浏览器打开面板管理规则。

它只做**纯转发**，不终结任何代理协议：每条规则在本机监听一个端口，把收到的字节原样转发到落地节点的地址和端口。手机节点配置里填中转机的入口地址，落地节点仍走它自己的协议（例如 SOCKS5），账号密码不用改。

## 需要什么

- 一台 Linux VPS（中转机），能用 root 登录
- VPS 上有 Python 3.8 或更高版本（不需要 pip、不需要装任何第三方包）
- 一台能上网的电脑（Mac），用来上传文件

## 部署步骤

### 第 1 步（Mac 本地）：把安装包传到 VPS

用 FinalShell 的 SFTP，把整个 `forward-panel` 文件夹拖到 VPS 的 `/root/` 目录下。
传完后 VPS 上应该有：`/root/forward-panel/install.sh`、`/root/forward-panel/panel.py`、`/root/forward-panel/static/index.html`。

### 第 2 步（VPS 终端）：进入安装包目录

```bash
cd /root/forward-panel
```

### 第 3 步（VPS 终端）：运行安装脚本

```bash
bash install.sh
```

### 第 4 步（VPS 终端）：按提示设置管理员密码

安装脚本会静默读取两次密码（屏幕不回显）。密码只存加盐哈希，不会以明文保存。
如果已装过一次，脚本会问是否重置密码，选否就保留原密码。

### 第 5 步（Mac 浏览器）：打开面板并登录

```
http://你的VPS_IP:2080
```

用第 4 步设置的管理员密码登录。默认端口是 2080；安装时换端口的方法：

```bash
PANEL_PORT=3080 bash install.sh
```

### 第 6 步（面板里）：添加一条转发规则

点“添加规则”，填：

- 名称：例如 `直播手机01`
- 分组：例如 `直播分组`（留空为未分组）
- 监听端口：留空则随机（10000-65535）
- 目标地址：落地节点的 SOCKS5 地址和端口，例如 `203.0.113.10:1080`

点确定后，面板会弹窗大字显示这条规则的入口地址，例如 `203.0.113.1:24567`。

### 第 7 步（手机节点配置）：把入口地址复制过去

把弹窗里的入口地址复制到手机节点配置里，**替换原来的落地地址**；SOCKS5 账号密码不用改。
保存后，手机先连中转机，中转机再转发到落地节点出网。

## 日常使用

- 规则列表里每条规则都有“复制入口地址”按钮，换手机、改节点时不用重新翻弹窗。
- “暂停”会立即停止该条规则的转发，“启用”恢复；流量统计每 5 秒刷新一次。
- 规则存在 `/opt/forward-panel/data/rules.json`，服务重启后自动恢复，启用中的规则自动重新开始转发。
- 查看运行日志（VPS 终端）：

```bash
journalctl -u forward-panel -f
```

## 安全提醒

- 管理员密码设强一点，不要用弱口令。
- 面板端口不要裸奔在公网，建议二选一：
  - 只放行你自己的 IP（VPS 终端，`你的IP` 换成你上网的公网 IP）：

```bash
ufw allow from 你的IP to any port 2080
```

  - 或者只走 SSH 隧道访问（Mac 本地终端，隧道建好后浏览器开 `http://127.0.0.1:2080`）：

```bash
ssh -L 2080:localhost:2080 root@你的VPS_IP
```

## 卸载

第 1 步（VPS 终端）：进入安装包目录：

```bash
cd /root/forward-panel
```

第 2 步（VPS 终端）：运行卸载脚本（卸载前规则会自动备份到 `/tmp`，文件名带时间戳）：

```bash
bash uninstall.sh
```

## 文件说明

- `panel.py`：后端。提供面板页面和 JSON 接口、管理规则、执行转发（TCP+UDP 用户态转发，每条规则一个转发器）、统计每条规则流量。主机禁 UDP 时记一条警告并只转 TCP。
- `static/index.html`：前端页面（原生 JS，无构建步骤）。
- `install.sh`：安装脚本（root 运行）：装到 `/opt/forward-panel`，注册 systemd 服务（失败自动重启）。
- `uninstall.sh`：卸载脚本（root 运行）：停服务、删文件，卸载前备份规则。
