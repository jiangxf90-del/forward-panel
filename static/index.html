添加规则

这是本台中转机上监听的端口，生成后会连同中转机地址一起作为入口地址。
一行一个目标？本面板 v1 每条规则只填一个目标：落地节点的 SOCKS5 地址和端口。
直转：中转机直接连目标地址。隧道：中转机先连落地机上的隧道端，隧道端再本地连目标；vendor 落地装不了隧道端，只能用直转。
落地机上跑：python3 tunnel-agent.py --listen 20000 --target 127.0.0.1:1080，目标地址栏此时填隧道端看到的本地目标，通常是 127.0.0.1:端口。
0 = 不限。直播规则建议：IP 限制填 1，只认第一个连上的设备，配置被复制到别的手机上 IP 不同就连不上。
IP 限制在规则暂停再启用、或面板重启后会重新认第一个连上的设备；直播手机换了上网 IP 时，暂停再启用一次即可重新锁定。

编辑规则

改端口后入口地址会变，手机节点配置里也要跟着换成新入口地址。

规则已创建，入口地址如下

  1. 复制上面的入口地址，粘贴到手机节点配置里，替换原来的落地地址；
  2. SOCKS5 账号密码不用改，保持原来落地节点的账号密码；
  3. 保存节点后，手机先连中转机，中转机再转发到落地节点出网。
